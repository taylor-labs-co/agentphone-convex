`agentphone-convex` is a Convex component that integrates the [AgentPhone](https://agentphone.ai/) AI messaging and voice platform directly into your Convex backend. Rather than building and maintaining your own HTTP layer, webhook handler, and state-sync logic, you install one component and get a fully typed API client, Convex-native resource mirrors that update reactively, a durable outbound queue with idempotency and retries, signed and replay-protected webhook delivery, and an indexed event history—all in one package.

## Who it's for

If you are building on Convex and want to add AI-powered SMS, iMessage, WhatsApp, or voice calling to your application, `agentphone-convex` gives you a production-ready integration without leaving the Convex programming model. Your queries, mutations, and actions work with local Convex tables rather than calling AgentPhone on every read, so your UI stays reactive and your logic stays serverless.

## Prerequisites

Before you start, make sure you have:

- A **Convex project** (Node.js >= 20, `convex` >= 1.0)
- An **AgentPhone account** and a project API key from [agentphone.ai](https://agentphone.ai/)
- At least one AgentPhone **agent** configured in your AgentPhone project

<Note>
  The `agentphone-convex` package is Convex backend code and cannot run in the browser. All `AgentPhone` client usage must be inside `convex/` functions.
</Note>

## Authorization boundary

Component scopes isolate records from one another, but they do not authorize your application's users. Any public Convex function that returns AgentPhone data must authenticate the caller and verify their access to the configured scope. The package exports a `requireAgentPhoneScopeAccess` helper for JWT-based applications, but you can substitute any application-level membership check.

<Warning>
  Checking only that a user is signed in is not sufficient when multiple users or tenants share a deployment. Always verify that the caller has access to the specific scope being queried.
</Warning>
