`agentphone-convex` is a Convex component that brings [AgentPhone](https://agentphone.ai/) messaging and voice capabilities directly into your Convex backend. It gives you a typed API client, reactive local mirrors of all AgentPhone resources, a durable outbound queue with retries and idempotency, and signed webhook delivery — all with the reactivity and consistency guarantees of Convex.

## Get started

<Steps>
  <Step title="Install the package">
    ```bash
    npm install agentphone-convex
    ```
  </Step>
  <Step title="Mount the component">
    Add the component to your `convex/convex.config.ts`:
    ```ts convex/convex.config.ts
    import { defineApp } from "convex/server";
    import agentphone from "agentphone-convex/convex.config.js";

    const app = defineApp();
    app.use(agentphone);
    export default app;
    ```
  </Step>
  <Step title="Set your API key">
    ```bash
    npx convex env set AGENTPHONE_API_KEY=your_key
    ```
  </Step>
  <Step title="Create a shared client">
    ```ts convex/agentphone.ts
    import { AgentPhone } from "agentphone-convex";
    import { components } from "./_generated/api.js";

    export const agentphone = new AgentPhone(components.agentphone, {
      defaultAgentId: process.env.AGENTPHONE_AGENT_ID,
    });
    ```
  </Step>
</Steps>

Follow the [Quickstart](/quickstart) for a complete walkthrough.
