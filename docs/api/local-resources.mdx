---
title: "Local Resource Mirrors — Reactive Convex Queries"
sidebarTitle: "Local Resources"
description: "Query reactive local mirrors of agents, numbers, conversations, messages, and calls stored in your Convex database by the agentphone-convex component."
---

The `AgentPhone` client maintains scoped, index-backed mirrors of every resource that flows through the component — agents, numbers, conversations, messages, calls, transcripts, and recordings. Because these mirrors live in your own Convex tables, you can read them from any query, mutation, or action context without an extra network round-trip to the AgentPhone API. All reads are index-backed, default to 50 records, and reject limits above 100.

<Note>
  Mirrors are kept current automatically by incoming webhooks, direct sends and calls, queued outbound work, transcript fetches, and explicit sync calls. You can also backfill them on demand using the [Sync API](/api/sync).
</Note>

---

## Agents

### `listLocalAgents`

Returns all locally mirrored agents for the configured scope.

```ts
const agents = await agentphone.listLocalAgents(ctx, { limit: 25 });
```

**Parameters**

<ParamField body="ctx" type="QueryCtx | MutationCtx | ActionCtx" required>
  A Convex query, mutation, or action context.
</ParamField>

<ParamField body="limit" type="number">
  Maximum number of agents to return. Defaults to `50`. Maximum is `100`.
</ParamField>

**Returns** `AgentPhoneAgent[]`

---

## Conversations

### `listLocalConversations`

Returns locally mirrored conversations, optionally filtered by agent, number, or counterparty. Results are ordered most-recent-activity first.

```ts
const conversations = await agentphone.listLocalConversations(ctx, {
  agentId: "agt_abc123",
  limit: 20,
});
```

**Parameters**

<ParamField body="ctx" type="QueryCtx | MutationCtx | ActionCtx" required>
  A Convex query, mutation, or action context.
</ParamField>

<ParamField body="agentId" type="string">
  Filter conversations to a specific agent.
</ParamField>

<ParamField body="numberId" type="string">
  Filter conversations to a specific phone number.
</ParamField>

<ParamField body="counterparty" type="string">
  Filter conversations to a specific counterparty phone number or identifier.
</ParamField>

<ParamField body="limit" type="number">
  Maximum number of conversations to return. Defaults to `50`. Maximum is `100`.
</ParamField>

<Tip>
  Providing `agentId`, `numberId`, or `counterparty` each routes to a dedicated index. Omitting all three uses the `by_scope_and_last_activity_at` index for a recency-ordered full list.
</Tip>

**Returns** `AgentPhoneConversation[]`

## Combined State

### `getLatestConversationState`

Returns a conversation and its most recent messages in a single read. Returns `null` if the conversation is not found locally.

```ts
export const conversationState = query({
  args: { conversationId: v.string() },
  returns: v.any(),
  handler: async (ctx, args) => {
    return await agentphone.getLatestConversationState(ctx, {
      ...args,
      messageLimit: 25,
    });
  },
});
```

**Parameters**

<ParamField body="ctx" type="QueryCtx | MutationCtx | ActionCtx" required>
  A Convex query, mutation, or action context.
</ParamField>

<ParamField body="conversationId" type="string" required>
  The AgentPhone conversation ID.
</ParamField>

<ParamField body="messageLimit" type="number">
  Maximum number of recent messages to include. Defaults to `20`. Maximum is `100`.
</ParamField>

**Returns**

```ts
{
  conversation: AgentPhoneConversation;
  messages: AgentPhoneMessage[];
} | null
```

<ResponseField name="conversation" type="AgentPhoneConversation">
  The locally mirrored conversation record.
</ResponseField>

<ResponseField name="messages" type="AgentPhoneMessage[]">
  The most recent messages in the conversation, ordered most-recent first.
</ResponseField>

## Exported Validators

The client exports a Convex validator for every mirrored resource type. Use these in your own query and mutation return type annotations.

```ts
import {
  agentValidator,
  numberValidator,
  conversationValidator,
  messageValidator,
  callValidator,
  callTranscriptValidator,
  callRecordingValidator,
} from "agentphone-convex";
```

| Export | Validates |
|---|---|
| `agentValidator` | `AgentPhoneAgent` |
| `numberValidator` | `AgentPhoneNumber` |
| `conversationValidator` | `AgentPhoneConversation` |
| `messageValidator` | `AgentPhoneMessage` |
| `callValidator` | `AgentPhoneCall` |
| `callTranscriptValidator` | `AgentPhoneCallTranscript` |
| `callRecordingValidator` | `AgentPhoneCallRecording` |
