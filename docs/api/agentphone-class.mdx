The `AgentPhone` class is the single entry point for every interaction with the AgentPhone platform from your Convex backend. You instantiate it once in your `convex/` directory, pass the `components.agentphone` handle and an optional options object, then call its methods from actions, mutations, or queries throughout your app.

## Constructor

```ts
new AgentPhone(components.agentphone, options?: AgentPhoneOptions)
```

The first argument must be the `components.agentphone` handle generated by Convex when you install the component. The second argument accepts an `AgentPhoneOptions` object — all fields are optional. See the [Configuration Reference](/api/configuration) for the full list of options.

```ts
import { AgentPhone } from "agentphone-convex";
import { components } from "./_generated/api.js";

export const agentphone = new AgentPhone(components.agentphone, {
  defaultAgentId: process.env.AGENTPHONE_AGENT_ID,
  defaultNumberId: process.env.AGENTPHONE_NUMBER_ID,
  scope: "default",
});
```

## Public Readable Properties

These properties are set at construction time and cannot be changed afterward.

<ResponseField name="scope" type="string" required>
  The isolation scope for all records, delivery IDs, webhook secrets, and queue
  idempotency keys stored by this client. Defaults to `"default"`. Use a stable
  tenant or workspace ID when a single Convex deployment serves multiple
  AgentPhone projects.
</ResponseField>

<ResponseField name="httpPrefix" type="string" required>
  The URL path prefix under which the webhook route is registered. Defaults to
  `"/agentphone"`. The full webhook endpoint becomes
  `{CONVEX_SITE_URL}{httpPrefix}/webhook`.
</ResponseField>

<ResponseField name="subAccountId" type="string">
  Optional sub-account identifier forwarded to all API calls that do not supply
  their own `subAccountId`. Usually set for you by
  [`forSubAccount`](/api/sub-accounts).
</ResponseField>

<ResponseField name="defaultAgentId" type="string">
  Optional agent ID used as a fallback whenever a method accepts `agentId` and
  none is provided at the call site.
</ResponseField>

<ResponseField name="defaultNumberId" type="string">
  Optional number ID used as a fallback whenever a method accepts `numberId` and
  none is provided at the call site.
</ResponseField>

## Public Writable Callback Properties

These properties can be reassigned after construction, typically right after you create the instance. Each must be an internal Convex mutation reference matching the `EventHandler` signature: it accepts `{ event, scope }` and returns a `VoiceWebhookResponse` or `null`. Spread the exported `eventCallbackArgs` into the handler's `args` to declare them.

<ResponseField name="incomingEventCallback" type="EventHandler">
  Catch-all callback invoked for every incoming webhook event that does not
  match a more specific override below. Assign `internal.yourModule.yourHandler`
  to activate it.
</ResponseField>

<ResponseField name="incomingMessageCallback" type="EventHandler">
  Override callback for `agent.message` events. When set, it takes precedence
  over `incomingEventCallback` for that event type.
</ResponseField>

<ResponseField name="reactionCallback" type="EventHandler">
  Override callback for `agent.reaction` events.
</ResponseField>

<ResponseField name="callEndedCallback" type="EventHandler">
  Override callback for `agent.call_ended` events.
</ResponseField>

```ts
import { internal } from "./_generated/api.js";
import { agentphone } from "./agentphone.js";

agentphone.incomingEventCallback = internal.agentphone.handleEvent;
agentphone.callEndedCallback     = internal.calls.onCallEnded;
```

<Note>
  `scope` tells a callback which tenant the delivery belongs to: the client's own
  scope, or a `<scope>:sub:<subAccountId>` scope when the delivery came from a
  sub-account webhook. One handler can therefore serve every tenant a deployment
  hosts.
</Note>

<Note>
  Voice callbacks run synchronously inside the event-insert transaction so their
  return value can be forwarded back to AgentPhone as a `VoiceWebhookResponse`.
  Non-voice callbacks run asynchronously and are retried with exponential backoff
  before becoming a dead letter.
</Note>

## The `request` Escape Hatch

When you need to call an AgentPhone endpoint that does not yet have a dedicated helper, use `request<T>`. It forwards your `method`, `path`, optional `query` parameters, and optional `body` to the provider using the client's configured API key, base URL, and sub-account ID.

```ts
const result = await agentphone.request<MyResponse>(ctx, {
  method: "GET",
  path: "usage/daily",
  query: { days: 30 },
});
```

<ParamField body="method" type='"GET" | "POST" | "PATCH" | "PUT" | "DELETE"' required>
  The HTTP method to use.
</ParamField>

<ParamField body="path" type="string" required>
  The API path relative to the AgentPhone base URL, e.g. `"usage/daily"` or
  `"agents/ag_123/calls"`.
</ParamField>

<ParamField body="query" type="Record<string, string | number | boolean | null>">
  Query string parameters. Keys with `undefined` values are omitted.
</ParamField>

<ParamField body="body" type="JsonValue">
  Request body. Serialized as JSON.
</ParamField>

<ParamField body="subAccountId" type="string">
  Per-request sub-account override. Falls back to the client's `subAccountId`
  when omitted.
</ParamField>

<Tip>
  Streaming transcripts and large binary recording responses should use an
  app-owned HTTP action instead of routing through Convex values.
</Tip>

## Exported Validators

The package re-exports Convex validators for every mirrored resource table. Use them in your own query/mutation return type annotations.

```ts
import {
  eventValidator,
  storedEventValidator,
  voiceResponseValidator,
  agentValidator,
  numberValidator,
  conversationValidator,
  messageValidator,
  callValidator,
  callTranscriptValidator,
  callRecordingValidator,
  webhookDeliveryValidator,
  outboundRequestValidator,
  subAccountValidator,
  eventCallbackArgs,
} from "agentphone-convex";
```

| Export | Description |
|--------|-------------|
| `eventValidator` | Validates an incoming `AgentPhoneEvent` payload. |
| `storedEventValidator` | Validator for a stored event row. |
| `voiceResponseValidator` | Validates a synchronous `VoiceWebhookResponse`. |
| `agentValidator` | Validator for a mirrored `AgentPhoneAgent` record. |
| `numberValidator` | Validator for a mirrored `AgentPhoneNumber` record. |
| `conversationValidator` | Validator for a mirrored `AgentPhoneConversation` record. |
| `messageValidator` | Validator for a mirrored `AgentPhoneMessage` record. |
| `callValidator` | Validator for a mirrored `AgentPhoneCall` record. |
| `callTranscriptValidator` | Validator for a mirrored `AgentPhoneCallTranscript` record. |
| `callRecordingValidator` | Validator for a mirrored `AgentPhoneCallRecording` record. |
| `webhookDeliveryValidator` | Validator for a `AgentPhoneWebhookDelivery` record. |
| `outboundRequestValidator` | Validator for a `AgentPhoneOutboundRequest` record. |
| `subAccountValidator` | Validator for an `AgentPhoneSubAccount` registry entry. |
| `eventCallbackArgs` | Argument validators for a webhook callback: `{ event, scope }`. |

## Exported Types

These TypeScript types are inferred from the validators above and re-exported for use in your application code.

| Type | Description |
|------|-------------|
| `Event` | The incoming AgentPhone event payload — the shape of `event` in your `EventHandler` callbacks. |
| `AgentPhoneAgent` | A local mirror of an AgentPhone agent resource. |
| `AgentPhoneNumber` | A local mirror of a provisioned phone number. |
| `AgentPhoneConversation` | A local mirror of a conversation record. |
| `AgentPhoneMessage` | A local mirror of a message record. |
| `AgentPhoneCall` | A local mirror of a call record. |
| `AgentPhoneCallTranscript` | A local mirror of a call transcript. |
| `AgentPhoneCallRecording` | A local mirror of a call recording. |
| `AgentPhoneWebhookDelivery` | A webhook delivery record. |
| `AgentPhoneOutboundRequest` | A durable outbound queue entry. |
| `AgentPhoneSubAccount` | A sub-account registry entry, including in-flight provisioning claims. |
| `AgentPhoneProvisionedSubAccount` | A registry entry AgentPhone has already assigned an id to. |
| `EventHandler` | The type for all callback properties — an internal Convex mutation reference that accepts `{ event: AgentPhoneEvent; scope: string }` and returns `VoiceWebhookResponse \| null`. |
